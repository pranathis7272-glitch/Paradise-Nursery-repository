# Paradise Nursery

A React plant shop application built with Vite, React Router, and Redux Toolkit.

## Features
- Landing page with a Get Started button
- Company information page
- Plant listings grouped by category
- Add items to a shopping cart
- Increase/decrease quantities and remove items
- Live cart count and total price

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
